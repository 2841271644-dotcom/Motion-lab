SVGA 压缩二级页面升级说明（保持尺寸修复版）

用途
压缩只优化文件体积。画布尺寸、每张素材的像素宽高、素材位置与变换、帧率、帧数、时长和音轨保持原样。

本次修复（2026-11-07）
- 移除素材分辨率 / 缩放选项，图片编码始终使用原始像素尺寸。
- 旧版本保存的缩放数值会被忽略，不影响新的压缩结果。
- 所有被替换的图片资源均检查原始宽高；发现尺寸变化时停止压缩并阻止下载该结果。
- PNG、JPEG、WebP 图片尺寸校验已验证。
- 保留原来的无损优化、均衡压缩、强力压缩三个预设。
- 自定义仅提供 PNG 目标颜色数（8–256）、JPEG 质量（1–100）、容器压缩等级（1–9）。
- 自定义默认：128 色、JPEG 质量 80、容器压缩等级 9；支持记忆设置、恢复默认和范围校验。
- 切换模式或更改数值后清除旧结果，需要重新压缩。
- 未获得更小体积时保留原素材或原文件，不输出更大的压缩文件。

安装步骤
1. 解压，将包内所有文件与文件夹合并到已有 Motion-lab 仓库根目录，替换同名文件。
2. 保留原项目的 vendor、motion-lab.js、FFmpeg 相关文件及其他原有文件。
3. 提交修改并 Push origin，等待 GitHub Pages 部署完成。
4. 打开原网站，Ctrl+F5 强制刷新，进入 SVGA 压缩页并重新导入原始 SVGA。
5. 不要使用上一版已经缩小过的导出文件作为原文件；请重新使用未压缩的原始素材。

原有功能
- 支持 SVGA 1.x（ZIP/JSON）与 2.x（zlib/Protobuf），支持无扩展名原始 SVGA。
- 文件选择 / 拖放、双预览、播放暂停、清空、体积对比、下载 SVGA。
- 文件在浏览器本地处理，不上传。
- 原格式转换逻辑未修改。

验证
- Node 核心 36 项检查通过，包含尺寸变化拒绝、旧缩放值忽略、两种容器、参数校验、音频 / 未知字段保留与结果不变大。
- 70 项图像与容器回归使用 Node Canvas 运行通过，包含实际 PNG / JPEG 编码、透明度类别、全部预设、自定义模式、逐张素材尺寸与动画数据保持。
- PNG / JPEG / WebP 的原始图片尺寸读取通过真实编码结果检查。
- 本轮未重新进行浏览器交互验收。

注意
均衡、强力和自定义会改变颜色或 JPEG 编码质量，渐变、高光和半透明边缘可能发生变化，但不会改变画布或素材尺寸。
压缩率取决于源文件，已充分压缩的文件可能无法继续变小。
本包为已有 GitHub 仓库的增量升级包；预览站已更新，GitHub Pages 需自行提交此包才会更新。
